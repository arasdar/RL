# (Deep) RL: Deep Reinforcement Learning
This repository is dedicated to implementing reinforcement learning algorithms using neural networks, such as Deep Q-Learning (DQL) and Deep Q-Network (DQN) for discrete action spaces, as well as Deep Deterministic Policy Gradients (DDPG), a model-free actor-critic method for continuous action spaces, in TensorFlow and PyTorch with Jupyter Notebook.
